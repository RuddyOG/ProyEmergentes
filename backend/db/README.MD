# Base de Datos GAMC (MongoDB)

Este módulo contiene la configuración y pruebas iniciales de la base de datos MONGO DB utilizada en el proyecto **Emergentes Big Data**.

## 📂 Archivos
- `createDatabase.js`: Crea la base de datos `gamc_datos` y las colecciones `sonido`, `aire`, y `soterrado`.
- `insertExamples.js`: Inserta datos de ejemplo para cada tipo de sensor.
